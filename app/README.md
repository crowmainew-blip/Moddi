# moddi — แอปแปลเกมเป็นภาษาไทย

รองรับเกม **RPG Maker MV / MZ** และ **Unity** (Windows)

## เริ่มใช้
1. แตกไฟล์ zip ไปไว้ที่ไหนก็ได้ (อย่าเปิดจากใน zip ตรงๆ)
2. ดับเบิลคลิก **start.bat**
   - ถ้าเครื่องยังไม่มี Python แอปจะถามว่าจะติดตั้งให้ไหม กด Y
3. แอปเปิดในเบราว์เซอร์ → แท็บ **แปลเกม**
4. **เลือกโฟลเดอร์** เกม (โฟลเดอร์ที่มี Game.exe) → **ตรวจเกม**
5. ตัวแปลออฟไลน์ (ฟรี): ทำตามปุ่มในกล่องตัวแปลทีละขั้น
   ติดตั้ง Ollama → เปิด Ollama → โหลดโมเดล (ครั้งแรกครั้งเดียว)
6. **แปลทั้งเกม** → ตรวจแก้ → **ติดตั้งแล้วเปิดเกม**
7. ไม่ชอบ กด **ถอน mod** เกมกลับเป็นต้นฉบับทุกไฟล์

## เกม Unity
moddi ใช้ BepInEx + XUnity.AutoTranslator (โอเพนซอร์ส) ใส่คำแปลลงเกม มี 2 ทางที่ใช้ร่วมกัน
**สแกนล่วงหน้า** ดึงข้อความจากไฟล์ภาษา ไฟล์ asset (TextAsset, I2 Localization ฯลฯ) และโค้ดของเกม แล้วแปลทั้งหมดโดยไม่ต้องเล่น
**แปลสด** ข้อความที่สแกนไม่เจอ จะถูกแปลตอนโผล่บนจอระหว่างเล่น

1. เลือกโฟลเดอร์เกม (ที่มีไฟล์ .exe ของเกมกับโฟลเดอร์ `ชื่อเกม_Data`) → ตรวจเกม
2. เลือกภาษาต้นฉบับ → **ติดตั้งระบบแปล** (ครั้งแรกต้องต่อเน็ต แอปโหลดจาก GitHub ให้เอง)
3. **สแกนหาข้อความในเกม** (ครั้งแรกแอปจะติดตั้งตัวอ่านไฟล์ Unity ให้ 1-2 นาที) → ติ๊กแหล่งที่ต้องการ → **แปลข้อความที่สแกนได้**
4. เปิด moddi ทิ้งไว้ กด **เปิดเกม** ส่วนที่ขาดจะถูกแปลระหว่างเล่น
5. กด **รีเฟรชข้อความ** ตรวจแก้ แล้วกด **ติดตั้ง** ในเกมกด Alt+R เพื่อโหลดคำแปลใหม่
5. ไม่เอาแล้ว กด **ถอน mod** แอปลบ BepInEx/XUnity ที่ใส่ไปออกหมด ไฟล์เกมที่ถูกทับจะได้คืน

ข้อจำกัด
- สแกนได้มากน้อยต่างกันแต่ละเกม เกมที่เขียนข้อความไว้ในโค้ด หรือเข้ารหัสไฟล์ จะสแกนได้น้อย
- "ข้อความในโค้ด" มักปนข้อความที่ผู้เล่นไม่เห็น (log, คีย์) แอปเลยไม่ได้เลือกไว้ให้ ดูตัวอย่างก่อนติ๊ก
- เกม Unity แบบ IL2CPP (มีไฟล์ GameAssembly.dll) รองรับแบบทดลอง บางข้อความอาจไม่ถูกแปล
- ตัวเลือก "แก้ภาษาไทยในเกม" (เปิดไว้เป็นค่าเริ่มต้น) ใช้ฟอนต์ Tahoma และจัดสระ/วรรณยุกต์ไม่ให้ลอยหรือทับกัน ถ้าปิดแล้วภาษาไทยดูดีกว่า ก็ปิดได้ เกมที่ใช้ TextMeshPro รุ่นเก่าอาจยังแสดงไทยเป็นกล่อง
- Unity ตัดบรรทัดตามช่องว่างเท่านั้น ประโยคไทยยาวๆ ที่ไม่มีเว้นวรรคอาจล้นกล่อง ใส่เว้นวรรคระหว่างวลีในหน้าตรวจแก้ช่วยได้
- โปรแกรมแอนตี้ไวรัสบางตัวเตือนไฟล์ winhttp.dll ของ BepInEx ไฟล์นี้เป็นตัวโหลด mod ปกติ
- ถ้าเกมมี BepInEx อยู่แล้ว moddi จะใส่แค่ XUnity และถอนแค่ของตัวเอง

## เลือกโมเดล
| โมเดล | เหมาะกับ | ขนาด |
|---|---|---|
| gemma3:4b | คอมทั่วไป (RAM 8 GB ขึ้นไป) | ~3.3 GB |
| gemma3:12b | การ์ดจอ 12 GB ขึ้นไป แปลสวยกว่า | ~8 GB |
| AI ออนไลน์ | ใส่ API key เอง (OpenRouter / OpenAI / Typhoon) เร็วและสวยสุด | - |

ถ้าคอมไม่มีการ์ดจอ แปลออฟไลน์จะช้า เกมขนาดกลางอาจใช้เวลาหลายชั่วโมง เปิดทิ้งไว้ได้ และบรรทัดที่แปลแล้วจะไม่หาย กดแปลต่อได้เสมอ

## เกมที่มีระบบกันโกง
ถ้าเกมมี Easy Anti-Cheat, BattlEye, ACE, GameGuard, XIGNCODE ฯลฯ moddi จะไม่ติดตั้งอะไรลงเกม เพราะการใส่ mod อาจทำให้โดนแบนไอดี
ยังแปลและส่งออกไฟล์ mod ได้ แต่ไม่ควรเอาไปใช้กับเกมออนไลน์

## ถ้ามีปัญหา
- **"ไม่เจอเกม RPG Maker"** ต้องเลือกโฟลเดอร์ที่มี Game.exe และโฟลเดอร์ `www` หรือ `data` ถ้าเกมมีแค่ .exe ไฟล์เดียว แปลว่าถูกแพ็กไว้ รุ่นนี้ยังไม่รองรับ
- **ข้อความยาวล้นกล่อง** RPG Maker ไม่ตัดบรรทัดให้ แก้คำแปลให้สั้นลงในหน้าตรวจแก้
- **เกมอัปเดตแล้วภาษาไทยหาย** กดติดตั้งใหม่ บรรทัดที่เพิ่มมาใหม่กดแปลต่อได้
- บันทึกข้อผิดพลาดอยู่ที่ `%USERPROFILE%\.moddi\log.txt` ส่งไฟล์นี้มาให้ดูได้

## เก็บข้อมูลไว้ที่ไหน
- คำแปลทุกเกม: `%USERPROFILE%\.moddi\projects\`
- ไฟล์เกมเดิม: สำรองไว้ในโฟลเดอร์เกม `moddi_backup` (อย่าลบตอนติดตั้ง mod อยู่)
