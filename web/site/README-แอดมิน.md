# คลัง moddi — คู่มือแอดมิน (ช่วงเริ่มต้น)

เว็บทั้งเว็บมีแค่ `index.html` + `catalog.json` + โฟลเดอร์ `mods/`
อัปทั้งโฟลเดอร์ขึ้น Cloudflare Pages (ฟรี) ได้เลย ถ้าจะเพิ่มเกม แก้แค่ไฟล์ `catalog.json`

> เกมในไฟล์ตอนนี้เป็น **ตัวอย่างสมมติทั้งหมด** ลบออกก่อนเปิดจริง

## เพิ่มเกม 1 เกม
```json
{"id":"ชื่อ-ภาษาอังกฤษ-ขีดกลาง", "title":"ชื่อเกม", "platforms":["pc"] หรือ ["mobile"] หรือทั้งคู่,
 "engine":"Unity", "genre":"RPG",
 "mods":[ { ...คำแปล 1 ชุดต่อผู้แปล 1 คน... } ]}
```

ช่องเสริมของเกม: `steam_appid` (เลขเกมบน Steam ใช้ดึงรูปปก) หรือ `cover` (ลิงก์รูปเอง), `from_lang` (ภาษาต้นฉบับ เช่น en, ja)

## คำแปล 1 ชุด (mod)
| ช่อง | ใส่อะไร |
|---|---|
| `id` | รหัสไม่ซ้ำ |
| `tier` | ระดับที่ผู้แปล**อนุญาต**: 1 ฝากไฟล์ในคลัง · 2 ลิงก์ไปโพสต์ · 3 ลิงก์ไปเพจ · 4 ไม่อนุญาต (ไม่แสดง) |
| `install` | วิธีติดตั้ง: `moddi` (ติดตั้งในเว็บ), `extract`, `exe`, `modmanager`, `unity_xunity`, `steam_workshop`, `android_files`, `other` |
| `file` | (ระดับ 1) ที่อยู่ไฟล์ในโฟลเดอร์ `mods/` |
| `download_url` | (ระดับ 2) ลิงก์โพสต์ดาวน์โหลดของผู้แปล |
| `page_url` | (ระดับ 3) ลิงก์เพจผู้แปล |
| `steps` | ขั้นตอนเพิ่มเติมเฉพาะเกมนี้ (ไม่บังคับ) |
| `progress`, `version`, `updated` | แปลไปกี่ % / เวอร์ชัน / วันที่อัปเดต |
| `stats` | ตัวเลขแถบบนการ์ด: `total`, `fast` (แปลด่วน), `premium` (แปลพรีเมียม), `human` (คนเกลา) คัดลอกจากช่อง `stats` ในไฟล์ mod ที่แอปส่งออก |
| `translator` | `name`, `page_url`, `verified` (ยืนยันตัวตนแล้วไหม), `promptpay` (เบอร์หรือเลขบัตรที่ผู้แปลให้มาเอง) |

ปุ่ม "สนับสนุนผู้แปล" จะขึ้นเฉพาะคนที่ `verified: true` และมี `promptpay`
ห้ามเก็บเลขบัญชีธนาคาร ใช้แค่พร้อมเพย์ที่ผู้แปลเปิดเผยเองก็พอ

## กฎเหล็ก
- ไม่มีคำอนุญาต = ไม่ใส่ (ไม่ตอบ ถือว่าไม่อนุญาต)
- เก็บหลักฐานการอนุญาตไว้ทุกครั้ง (แคปแชต)
- ระดับ 1: ตรวจไฟล์ก่อนขึ้นทุกครั้ง ห้ามมีตัวเกมหรือ APK เกมทั้งตัว
- ผู้แปลขอเอาออกเมื่อไหร่ ลบทันที
- ไม่ลิสต์ mod ของเกมออนไลน์ที่มีระบบกันโกง (EAC, BattlEye, ACE ฯลฯ) เพราะคนเล่นอาจโดนแบน
- ค่า `promptpay` ใน `hub` คือพร้อมเพย์ของคลัง ตอนนี้เป็นเบอร์ตัวอย่าง ต้องเปลี่ยนก่อนเปิดจริง

## เปิดล็อกอิน Google จริง (ตอนนี้เป็นโหมดตัวอย่าง)
1. สมัคร supabase.com (ฟรี) → สร้างโปรเจกต์
2. SQL Editor → วางไฟล์ `supabase-setup.sql` → Run
3. Google Cloud Console → สร้าง OAuth Client ID (Web) → ใส่ Redirect URI ที่ Supabase ให้มา (Authentication → Providers → Google)
4. เอา Client ID / Secret ไปใส่ใน Supabase → เปิด Google provider
5. Authentication → URL Configuration → ใส่โดเมนเว็บเรา
6. ใส่ใน `catalog.json` ช่อง `hub`:
   `"supabase_url": "https://xxxx.supabase.co", "supabase_anon_key": "eyJ..."`
   (anon key เป็นคีย์สาธารณะ ใส่ในเว็บได้ ความปลอดภัยมาจาก RLS ในไฟล์ SQL)
7. คำขอผู้แปลจะเข้าตาราง `translator_requests` → ตรวจแล้วเปลี่ยน status เป็น `approved`
   แล้วใส่ `verified: true` + `promptpay` ให้ผู้แปลคนนั้นใน `catalog.json`

ลิงก์ดาวน์โหลดแอปใส่ที่ `hub.app_download_url`

## คลังชุมชน (ปุ่ม "อัพลงคลัง")

- ใครที่ล็อกอิน Google แล้วกด "อัพลงคลัง" ได้ทั้งในแอปและในหน้าเกลาภาษาบนเว็บ แปลไม่เสร็จก็อัพได้
- แอปรวมกับฉบับล่าสุดในคลังก่อนทุกครั้ง (คนเกลา > พรีเมียม > แปลด่วน ถ้าเท่ากันใช้อันใหม่) และดึงงานของคนอื่นกลับเข้าโปรเจกต์ของคนที่อัพ
- ทุกการอัพเป็นแถวใหม่ในตาราง `library_uploads` ถ้ามีคนอัพของเสีย: Supabase → Table editor → ตั้ง `hidden = true` ที่แถวนั้น หน้าเว็บจะกลับไปใช้ฉบับก่อนหน้าทันที
- ล็อกอินจากแอปบนคอม: ใน Supabase → Authentication → URL Configuration → Redirect URLs เพิ่ม `http://127.0.0.1:8765/**`
- ยังไม่ได้ใส่ supabase_url ใน catalog.json = โหมดตัวอย่าง ไฟล์ที่อัพเก็บในเบราว์เซอร์เครื่องนั้นเท่านั้น
